Where your saves live

On Windows, paste one of these into the File Explorer address bar.

Worlds%LOCALAPPDATA%\RSDragonwilds\Saved\SaveGames
Characters%LOCALAPPDATA%\RSDragonwilds\Saved\SaveCharacters
Server settingsC:\Program Files (x86)\Steam\steamapps\common\RuneScape Dragonwilds Dedicated Server\RSDragonwilds\Saved\Config\WindowsServer

DedicatedServer.ini is in that folder on a default Steam install of the dedicated server. Other installs keep it in RSDragonwilds\Saved\Config\WindowsServer inside the server folder.

Before you edit

  1. Close the game completely, or stop the dedicated server if you are editing its files.
  2. Copy the original file somewhere safe.
  3. Edit here, download, then replace the original with the downloaded file (same name).
  4. If Steam Cloud restores the old file, turn off Steam Cloud for the game while you swap it in.

Private by design

Your files are read and rewritten by code running in this tab. They are never uploaded or stored. Close the tab and they are gone.

The site keeps anonymous daily counts (visits, and which kind of file was opened or downloaded) to see what is used. No file names or contents, no IP addresses and no tracking cookies. Browsers with Do Not Track or Global Privacy Control are not counted. Feedback you send is stored so it can be read.
